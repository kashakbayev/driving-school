How This Site Was Built

This project uses plain HTML files written for Web Technologies I. The markup is intentionally unstyled, and all navigation links are relative so the site can be opened from the project folder.

The page files use <header>, <main>, and <footer> as the basic document structure. 

<nav aria-label="Main navigation">
  <ul>
    <li><a href="index.html">Home</a></li>
  </ul>
</nav>

To check files from the terminal, press Control + C to stop a command if it runs too long.

A successful file search can print index.html as one line of output.
